# Quotation Manager v1.0.11

## Update progress visibility, smoother scrolling, and fresher update checks

v1.0.11 is a focused user-experience revision built on the accepted v1.0.10 OTA architecture. It improves how updates are communicated during download/install/restart, fixes the shared scroll behavior that could visually jump in large chunks, and strengthens update-manifest revalidation to reduce stale GitHub Raw/CDN responses.

### What's new

- Adds a live determinate progress bar during OTA download and preparation.
- Shows transferred data for the target installer and rollback installer.
- Keeps the standalone updater visible after the main app closes so the transition no longer looks like a crash.
- Shows clear update stages such as installing, starting the updated application, validating startup health, and completing the update.
- Uses an indeterminate installation bar where Inno Setup does not provide a reliable percentage instead of showing a fake number.
- Adds an explicit message that Quotation Manager is restarting to finish the update and will reopen automatically.
- Improves rollback/recovery messaging if the new version fails health validation.
- Fixes the shared scrolling surface so mouse-wheel input moves in small consistent increments instead of large visual jumps.
- Adds support for precision touchpad/fractional wheel input and guards against unusually large driver deltas.
- Update-manifest checks now send explicit no-cache/revalidation headers and a local cache-busting query value to reduce stale `latest.json` responses.
- The approved GitHub manifest origin remains strictly validated; cache-busting does not loosen repository or URL trust restrictions.

### OTA and rollback safety retained

- HTTPS-only fixed GitHub release feed.
- Strict version, repository URL, schema, installer filename, size and SHA-256 validation.
- Mandatory verified rollback installer for the installed source version.
- Mandatory validated pre-update `.qmbak` recovery snapshot.
- Standalone update helper, post-install health validation, restart recovery and automatic rollback during the pre-validation window.

### Unchanged

- Database schema: **8**
- Installer AppId: unchanged
- QT / PI / INV numbering: unchanged
- Quotation/Proforma calculations: unchanged
- Tax Invoice calculations: unchanged
- PDF / Word / Excel renderers: unchanged
- Export-folder behavior: unchanged
- Draft-only Delete, reusable templates, revision history and Tax Invoice cancellation: unchanged
