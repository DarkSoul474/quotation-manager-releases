# Quotation Manager v1.0.10

## Update visibility and release transparency

v1.0.10 is a focused user-interface revision built on the accepted v1.0.9 OTA architecture. It does not change the database schema, business calculations, numbering, document renderers, export-folder behavior, templates, revision history, or Tax Invoice cancellation workflow.

### What's new

- Adds a live update-status indicator to the shared sidebar footer.
- Green indicator: **Application up to date** after a successful check confirms no newer release.
- Red indicator: **Update x.x.x available** when a newer verified release is published.
- Blue indicator: update check currently running.
- Neutral indicator: status not yet confirmed or the latest check could not complete.
- Shows the time of the latest completed update-check attempt.
- Points users to **Data & Diagnostics** for update details.
- Failed network/update checks never falsely report that the app is current.
- Update prompts now explicitly show the installed version and target version.
- Adds a mandatory **What's new in vX.X.X** section before Download & Install.
- OTA manifests with empty release notes are rejected.

### OTA and rollback safety retained

- HTTPS-only fixed GitHub release feed.
- Strict version, repository URL, schema, installer filename, size and SHA-256 validation.
- Mandatory verified rollback installer for the installed source version.
- Mandatory validated pre-update `.qmbak` recovery snapshot.
- Standalone update helper, post-install health validation, restart recovery and automatic rollback during the pre-validation window.

### Unchanged

- Database schema: **8**
- Installer AppId: unchanged
- QT / PI / INV numbering: unchanged
- Quotation/Proforma calculations: unchanged
- Tax Invoice calculations: unchanged
- PDF / Word / Excel renderers: unchanged
- Export-folder behavior: unchanged
- Draft-only Delete, reusable templates, revision history and Tax Invoice cancellation: unchanged
