# Quotation Manager v1.0.9

## OTA update foundation with rollback protection

This is the first production build that contains the Quotation Manager OTA update subsystem. Because v1.0.8 did not contain an updater, v1.0.9 must be installed once using the normal Windows installer. Supported later releases can then be delivered through OTA.

### Added

- Dedicated OTA update subsystem outside the business/calculation code.
- Manual **Check for Updates** under Data & Diagnostics.
- Quiet automatic startup update checks in packaged Windows builds.
- Strict HTTPS release-manifest validation against the approved public release repository.
- Exact installer filename/version validation.
- Bounded manifest and installer download sizes.
- Exact installer size and SHA-256 verification before execution.
- Mandatory verified rollback installer before an OTA can start.
- Mandatory pre-update `.qmbak` recovery snapshot with SQLite integrity validation.
- Standalone `QuotationUpdateHelper.exe` for installation monitoring and rollback.
- Post-install hidden startup/database health validation.
- Restart/interruption recovery for an update that was in progress.
- Automatic rollback during the pre-validation window if installation or health validation fails.

### Unchanged

- Database schema remains **8**.
- Installer AppId remains unchanged.
- QT / PI / INV numbering and financial-year sequence logic are unchanged.
- Quotation/Proforma and Tax Invoice calculations are unchanged.
- PDF/Word/Excel renderers are unchanged by the OTA feature.
- v1.0.8 export-folder behavior remains unchanged.
- Draft-only Delete, templates, revision history and Tax Invoice cancellation remain unchanged.

### Installer integrity

- File: `Quotation_Manager_Setup_v1.0.9.exe`

The installer is not Authenticode-signed in this release. SHA-256 verification protects integrity relative to the published OTA manifest; Authenticode remains the recommended next trust layer when a Windows code-signing certificate is available.
