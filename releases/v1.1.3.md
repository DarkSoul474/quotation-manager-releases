# Quotation Manager v1.1.3

## Proforma terminology, Word layout and OTA trust maintenance

v1.1.3 is a focused maintenance release built on v1.1.2. It keeps database schema 10, the installer AppId, PI numbering, business calculations and lifecycle rules unchanged.

### Changes

- Proforma customer-facing document title is now **PROFORMA** instead of **PROFORMA INVOICE**.
- The Proforma identifier is presented as **Reference Number** everywhere user-facing, including the editor, Proforma History, Preview, PDF, Word and Excel. Existing `PI-YYYY-YY-NNNN` numbering and internal `proforma_no` persistence are unchanged.
- Bill/Tax Invoice and Proforma Word exports now use an explicit right-side closing financial panel so Sub Total Amount through NET AMOUNT align with PDF/Excel; the GST rate-wise summary remains directly underneath.
- Windows OTA HTTPS now prefers the native Windows certificate trust engine through `truststore`, while TLS certificate verification and hostname verification remain mandatory.

### Unchanged

- Database schema: **10**
- Installer AppId: unchanged
- PI numbering and database persistence: unchanged
- Quotation and Tax Invoice business rules/calculations: unchanged
- Pre-update recovery backup, approved GitHub host validation, installer SHA-256/size checks, health validation and rollback protections remain enabled.
