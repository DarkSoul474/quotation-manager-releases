# Quotation Manager v1.1.1

## Focused UI and document-layout maintenance release

v1.1.1 is a maintenance revision built on v1.1.0. It keeps the v1.1.0 business workflows, domain separation and schema unchanged while correcting three presentation issues found during OTA validation.

### Fixes

- Fixes the update dialog's initial layout so the bottom action buttons remain visible without requiring the user to manually enlarge the window.
- Improves the update dialog's sizing/layout behavior for Windows display scaling while keeping the window resizable.
- Widens the lower GST-summary SGST column in Bill/Tax Invoice and Proforma Invoice Excel exports so monetary values are not visually squeezed.
- Centers non-applicable `-` placeholders in CGST/SGST/IGST cells in Bill/Tax Invoice and Proforma Invoice PDF and Word GST summaries while preserving numeric-value alignment.

### Unchanged

- Database schema: **10**
- Installer AppId: unchanged
- Quotation / Proforma / Tax Invoice business rules and calculations: unchanged
- Numbering and lifecycle rules: unchanged
- Existing v1.1.0 data remains compatible without migration.
- Mandatory pre-update backup, installer SHA-256/size verification, health validation and rollback protections remain enabled.
