# Quotation Manager v1.0.13

## Stage 2 R1 rollback / compatibility build

v1.0.13 is the Stage 2 R1 build used as the verified rollback boundary for the v1.1.0 OTA release path. It introduced the first-class Proforma Invoice domain separation and database schema 10.

### Included in this build

- Separate Proforma Invoice workspace, Dashboard entry and Proforma History.
- Independent Proforma repository, service and controller.
- Independent `PI-YYYY-YY-NNNN` numbering.
- Separate Proforma revisions, archive/restore and draft deletion behavior.
- Separate Proforma templates, defaults, export location and remembered Save As location.
- Separate Proforma terms, GST/tax mode and bank defaults.
- Bill-style Proforma PDF / Word / Excel rendering using `PROFORMA INVOICE` identity.
- Domain-aware autosave and session recovery.
- Schema 9 to 10 migration preserving existing Proforma numbers and lifecycle data.
- Quotation runtime/storage separation from the former combined Quotation/Proforma discriminator model.
- Neutral shared financial infrastructure with concrete Proforma and Tax Invoice domains kept independent.

### Role in OTA recovery

This installer is retained so a machine currently running v1.0.13 can be restored automatically if the v1.1.0 update fails validation. The updater also creates and verifies a pre-update `.qmbak` recovery snapshot before installation.
