# Quotation Manager v1.0.12

## Scroll boundary correction

v1.0.12 is a focused UI stability revision built on v1.0.11. It addresses the remaining shared-canvas scrolling glitch that could appear when page content was shorter than, or only slightly taller than, the visible viewport.

### What's new

- Fixes the shared scroll surface so content cannot visually jump outside its valid top/bottom boundaries.
- Uses explicit pixel-position clamping rather than relying on Tk canvas unit scrolling near short-content boundaries.
- Prevents scrolling entirely when the full page already fits within the visible viewport.
- Preserves smooth mouse-wheel behavior and precision touchpad support from v1.0.11.
- Applies centrally to shared scrollable screens such as Dashboard, Quotation and Proforma rather than patching individual pages.

### OTA and updater behavior retained

- Live download/preparation progress remains in place.
- Visible standalone update window remains in place during install/restart/validation.
- Cache-revalidated update-manifest checks remain in place.
- Mandatory rollback installer, validated `.qmbak`, health validation and pre-validation automatic rollback remain unchanged.

### Unchanged

- Database schema: **8**
- Installer AppId: unchanged
- QT / PI / INV numbering: unchanged
- Quotation/Proforma calculations: unchanged
- Tax Invoice calculations: unchanged
- PDF / Word / Excel renderers: unchanged
- Export-folder behavior: unchanged
- Templates, revision history, draft-only Delete and Tax Invoice cancellation: unchanged
